# `wang_zahl_kakeya_dimH`

Wang-Zahl: the three-dimensional Kakeya conjecture

This is an adaptation of the proof of Kakeya conjecture in 3 dimensions, a combination of the sticky Kakeya conjecture developed by a collaboration of Seed Prover and Nankai University, and the reduction of the full Kakeya conjecture to the sticky case by Project Numina, for lean-eval submission purposes. The sources are at https://github.com/M32026/3d-sticky-kakeya and https://github.com/project-numina/kakeya-3d.
